# Publication Notes

## Public Positioning

Present as a reusable automation governance pattern, not a one-off Instagram script.

## Demo Assets to Add

- One sanitized screenshot.
- One short terminal or UI walkthrough.
- One fixture-based validation run.

## Private Material to Exclude

- Real n8n workflow exports with credential IDs.
- Telegram bot tokens or chat IDs.
- Instagram access tokens.
- Render logs containing private URLs.
